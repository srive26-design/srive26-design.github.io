THE PROJECT

A game about
risk and return.

Slightly Dangerous LLC is my C++ console adventure. The player navigates generated mazes, faces creature encounters, and collects loot to meet a different quota on each of three workdays.

The central decision is how long to keep exploring. Items take up limited inventory space, some values remain unknown until appraisal, and money only becomes banked when the player reaches the designated exit and turns in the haul.

The source download contains the current LLC3 project, including its README and existing tests. It is a desktop console application.

DESIGN & IMPLEMENTATION

Systems that work together.

01

Procedural exploration

Generated mazes, distinct room descriptions, and three themed workdays. A discovered-only map and player-added markers support navigation.

02

Inventory & economy

An eight-slot inventory creates keep, leave, and replace decisions. Items have known or hidden values; the exit scanner appraises and banks the haul.

03

Encounters & progression

Creature encounters trigger minigames. Health, daily quotas, and collected lore connect individual rooms to the larger run.

04

Modular C++ structure

Separate source and header files handle the player, maze, rooms, items, monsters, story, HUD, animations, and shared input utilities.

A CLOSER LOOK / PLAYER STATE

Carried loot
isn’t banked money.

The turn-in method makes that distinction explicit: it totals the inventory’s actual value, credits the player, and then empties the inventory.

The lore journal is stored separately, so discovered clues remain available during the run after their physical items leave the inventory.

TRY THE PROJECT

Build it. Find your way out.

Build on Windows

Extract the source ZIP, open a terminal inside the LLC3 folder, and use the included build file with a configured clang++ C++17 toolchain.

.\build.bat
.\LLC3.exe

The included README documents the Windows ARM64 setup, the full compile command, and optional maze and inventory tests.
