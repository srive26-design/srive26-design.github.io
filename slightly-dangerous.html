Slightly Dangerous LLC

C++ console game · Sept. 2025 – Present

About the Project

Slightly Dangerous LLC is a console adventure game I built in C++. The player works three shifts inside generated mazes, explores rooms, encounters creatures, collects items, and tries to make enough money to meet each day’s quota.

The project started as a class game and has grown into a larger personal project as I continue improving the exploration, inventory, story, and game systems.

What I Built

  • Procedurally generated mazes with room-by-room exploration.
  • Inventory and loot systems with limited carrying space and item values.
  • Creature encounters and timed minigames.
  • Three-day progression with changing quotas and story content.
  • Separate C++ classes/files for the player, maze, rooms, items, monsters, story, HUD, and shared utilities.

Example

Loot is not counted as money until the player safely reaches the exit and turns it in.

int Player::turnInInventory()
{
    int payout = getActualInventoryValue();

    addMoney(payout);
    inventory.clear();

    return payout;
}
